# Product photos

Drop your images in this folder and list them in `src/data/products.js`.

- Use JPG, PNG or WebP, ideally 1600 px on the long side, 4:5 portrait.
- The first file in a product's `images` array is the main shot.
- The second file (for example `ring-1-lifestyle.jpg`) fades in when a visitor hovers the card.
- Any file that is missing is skipped and the drawn placeholder shows instead, so the page never breaks.
- Optional: add `hero.jpg` here to replace the sunset illustration in the hero section.

Expected names for the starter catalogue:
